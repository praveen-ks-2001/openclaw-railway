How to Use
Getting started after deployment

Connecting to OpenClaw after Setup

Once your Railway deploy is live and the /setup wizard is complete, follow these steps to connect to the OpenClaw UI from your browser.

You are already on the Admin Dashboard — this is your control panel for managing everything about your OpenClaw instance.

The Admin Dashboard — monitor status, view logs, manage pairing, and more
1
Open the OpenClaw UI

Click the "Open OpenClaw UI" button in the top-right corner of the admin dashboard, or use the OpenClaw UI link in the sidebar. This opens OpenClaw in a new tab. Keep the Admin Dashboard available for device approval.

2
Connect with the Gateway Secret if Asked

If OpenClaw asks for a Gateway secret or token, copy the Gateway Token from this dashboard's Status panel, paste it there, and click Connect. You may then see Approve this browser, a request ID, or a command to run on the Gateway host.

3
Approve the Pairing Request

Keep the requesting OpenClaw tab open. Return to Admin Dashboard → Pairing, find the matching request ID under Pending Requests, and click Approve. This dashboard performs the approval for you; you do not need to run the host command. If the request has expired, use Check now in OpenClaw to request it again.

The Pairing panel — approve the pending request from your browser
4
Return to OpenClaw

Return to the same OpenClaw tab. It reconnects automatically after approval; if needed, click Check now. Once it shows Connected, open a conversation and send a message.

Tip: OpenClaw Terminal Chat

The Terminal panel opens the interactive openclaw tui chat interface. It is not a container shell. Use the dashboard controls for logs, device approval, configuration, and Gateway restart; run host CLI commands through your container or Railway shell when needed.

The Admin Terminal — interactive OpenClaw TUI chat
About

OpenClaw Admin Panel

This admin panel is a lightweight management dashboard for your self-hosted OpenClaw instance on Railway. It lets you monitor the gateway status, stream live logs, manage device pairing, open an interactive terminal, and edit your OpenClaw configuration — all from the browser, no SSH or CLI required.

The admin panel is part of the openclaw-railway-template — an Express wrapper that handles process supervision, WebSocket proxying, auth, and a setup wizard so you can deploy OpenClaw on Railway with a single click.
